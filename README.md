# STEAM English — 교사 영어 100문장

인천 Global STEAM 3·4·5주차 수업에서 쓰는 영어 표현을 게임과 선택형 말하기로 익히는 웹앱입니다.

**학습 주소:** https://ddargi0410.github.io/steam-english-100/

로그인 없이 PC와 모바일에서 사용할 수 있습니다.

## 기본 학습

한 번에 다섯 문장을 다음 순서로 연습합니다.

1. **단어 뜻 게임** — 한국어 뜻에 맞는 영어 표현을 고릅니다.
2. **문장 배열** — 흩어진 단어를 눌러 문장을 만듭니다. 단어 되돌리기, 힌트와 정답 확인을 제공합니다.
3. **기억하기** — 한국어만 보고 영어를 떠올린 뒤 답을 열어 스스로 확인합니다.
4. **선택형 말하기** — 더 연습하고 싶을 때 음성인식이나 녹음으로 연습합니다.

마이크를 쓰지 않아도 학습을 마칠 수 있습니다. 기존 말하기 중심 연습도 선택할 수 있습니다. 힌트 사용·본인 확인·음성인식 확인을 구분하며, 본인 확인을 발음 평가나 음성인식 성공으로 표시하지 않습니다.

## 말하기 확인

- **편하게:** 목표 문장의 문맥 안에서 비슷하게 인식된 단어와 일부 인식 오류를 넓게 허용합니다. 숫자나 부정처럼 중요한 차이는 따로 확인합니다.
- **꼼꼼하게:** 축약형·숫자 표기 등을 정리한 뒤 예문과 일치하는지 확인합니다.
- 계속 잘못 인식될 때는 직접 말했는지 본인이 확인하고 연습을 완료할 수 있습니다.
- 문장 인식과 녹음은 동시에 실행하지 않습니다. 녹음·다시 듣기는 별도의 연습입니다.

이 앱은 **받아쓴 글자를 비교하는 연습 도구**입니다. 실제 발음·억양·유창성을 정밀 측정하거나 문장의 의미를 완전히 이해하는 서비스가 아닙니다. 인식 실패는 발음 오답으로 채점하지 않습니다.

갤럭시 등 Android에서는 Chrome 앱에서 HTTPS 학습 주소를 직접 여는 것을 권합니다. 음성인식은 인터넷 연결 및 기기·브라우저의 지원에 영향을 받습니다. 화면 전환으로 연습이 중단되면 돌아온 뒤 버튼을 눌러 이어갈 수 있습니다.

## 학습 기록과 음성

학습 기록은 현재 기기의 브라우저에 저장하며 기존 기록을 유지합니다. 다른 기기와 자동 동기화되지 않고 브라우저 데이터를 지우면 사라질 수 있습니다. 기록 내려받기를 제공합니다.

음성인식은 브라우저 제공 서비스에 음성을 전송할 수 있습니다. 별도 녹음은 브라우저 메모리에서 재생하며, 저장 버튼을 눌렀을 때 기기에 내려받습니다. 앱 자체에는 음성이나 학습 기록을 저장하는 서버가 없습니다.
