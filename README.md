# STEAM English — 교사 말하기 100

인천 Global STEAM 수업에서 사용할 교사 영어 표현 100문장을 연습하는 웹앱입니다.
3·4·5주차 수업 장면별로 듣기, 따라 말하기, 영어 가리고 말하기, 복습을 제공합니다.

## 사용하기

게시 주소: https://ddargi0410.github.io/steam-english-100/

로그인 없이 PC와 모바일에서 열 수 있습니다. 갤럭시 등 Android에서는 Chrome 앱을 직접 열고 주소를 붙여 넣어 주세요. 말하기는 HTTPS 주소에서 인터넷에 연결한 상태로 사용해 주세요.

- **말하고 문장 확인**: 브라우저가 인식한 문장과 목표 문장을 비교합니다.
- **내 목소리 녹음·다시 듣기**: 별도로 녹음하고 재생합니다. 문장 인식과 녹음은 동시에 실행하지 않습니다.
- 음성인식은 브라우저·기기·서비스 지원에 따라 사용하지 못할 수 있습니다. 녹음이 된다고 음성인식도 가능한 것은 아닙니다.
- 인식 실패는 오답으로 기록하지 않습니다. 지원되지 않는 환경에서도 듣기와 영어 가리기 등을 이용할 수 있습니다.
- 이 앱은 발음·억양·유창성을 정밀 평가하지 않습니다.

## 학습 기록과 음성

학습 진도는 현재 기기의 브라우저 저장소에 보관합니다. 다른 기기나 기존 사이트와 자동으로 동기화되지 않으며, 브라우저 데이터를 지우면 사라질 수 있습니다. 학습 기록 내려받기 기능을 제공합니다.

음성인식은 브라우저 제공 서비스에 음성을 전송할 수 있습니다. 별도 녹음은 브라우저 메모리에서 재생하고, 저장 버튼을 누른 경우 기기에 내려받습니다. 이 앱 자체에는 녹음을 저장하는 서버나 계정 기능이 없습니다.

## 구성

- `index.html`: 화면, 100문장, 학습·말하기 기능을 포함한 단일 파일
- `.nojekyll`: GitHub Pages에서 정적 파일 그대로 제공

빌드나 추가 패키지 설치는 필요하지 않습니다. GitHub Pages의 게시 소스를 `main` 브랜치의 루트로 설정합니다.
게시 주소를 바꾸면 `index.html`의 `WEB_APP_URL` 상수와 이 문서의 게시 주소를 수정합니다.
