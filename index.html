마이크 연결 유지 · 녹음은 버튼을 누를 때만
녹음과 문장 인식은 서로 다른 기능이에요.

녹음이 되어도 브라우저의 음성인식 서비스가 작동하지 않을 수 있어요. 앱 안에서 열렸다면 웹 주소를 복사해서 Chrome 앱의 주소창에 직접 붙여 넣어 주세요.

  1. 웹 버전 열기 ↗ — 링크를 눌러도 앱 안에서 계속 열릴 수 있어요. Chrome 앱을 직접 실행하고 위 주소를 주소창에 붙여 넣어 주세요. 로그인 없이 사용할 수 있어요.
  2. Chrome에서 이 웹사이트의 주소창 옆 사이트 정보·설정 → 권한 → 마이크 → 허용을 확인해 주세요. 메뉴 이름은 버전에 따라 달라요.
  3. Chrome 설정 → 사이트 설정 → 마이크에서 사이트가 마이크 사용을 요청할 수 있는지 확인해 주세요. 이 사이트가 차단 목록에 있으면 권한을 다시 설정해 주세요.
  4. Android 휴대폰이라면: 휴대폰 설정 → 앱 → Chrome → 권한 → 마이크 → 앱 사용 중에만 허용을 확인해 주세요. 휴대폰의 ‘마이크 액세스’도 켜져 있어야 해요.
  5. 허용 창에 ‘이 사이트에서 항상 허용’ 같은 선택지가 있으면 선택해 주세요. ‘이번만 허용’은 다시 물을 수 있어요. 웹 페이지를 새로고침한 뒤 ‘말하고 문장 확인’을 다시 눌러 주세요. 관리되는 기기라면 기관의 제한이 있을 수도 있어요.

인식이 달라도 직접 말한 뒤 ‘직접 말했어요 · 연습 완료’를 누르거나, 홈에서 게임 학습을 선택해 주세요.

학습한 문장
이번 연습 경험치
게임·말하기·학습 기록 안내
  • 기본 학습은 마이크 없이 끝낼 수 있어요. 단어 뜻 고르기, 예문 순서대로 문장 배열하기, 한국어를 보고 떠올리기를 진행합니다. 힌트나 정답을 보아도 연습 경험치를 받습니다. ‘학습한 문장’은 게임 또는 말하기 연습을 마친 문장이며, 숙달도나 발음 인증이 아닙니다. 게임 완료·본인 확인·힌트 사용·음성인식 확인은 학습 기록에 구분해 저장합니다.
  • 표현 일치 확인은 브라우저가 받아쓴 문장과 목표 문장을 비교합니다. 발음의 정확도·억양·유창성을 측정하거나 발음 점수를 매기지 않습니다.
  • 기본 ‘편하게’ 기준은 문장 전체에서 맞게 인식된 핵심 단어를 참고하여 일부 빠지거나 다르게 받아쓴 단어를 허용합니다. 예를 들어 문맥에 맞는 result/resort, which/ricard 혼동을 허용합니다. 숫자·부정·같다/다르다처럼 뜻을 바꾸는 표현은 따로 확인합니다. ‘꼼꼼하게’는 축약형·숫자 표기 등을 정리한 뒤 문장이 일치해야 통과합니다. 이 기능은 전사된 글자를 비교하는 연습 도구입니다. 모든 동의 표현이나 의미 차이를 이해하는 것은 아니며, 실제 발음 정확도를 평가하지 않습니다.
  • 음성인식 오류가 있을 수 있습니다. 인식된 말과 본인 녹음을 함께 확인하세요. 알아듣지 못한 경우는 오답이나 발음 오류로 채점하지 않습니다. 확정되지 않은 인식 내용은 참고용으로만 보여 줍니다.
  • 음성인식은 브라우저 제공 서비스로 전송될 수 있고 인터넷 연결이 필요할 수 있습니다. 문장 인식 중에는 앱의 녹음 기능을 함께 켜지 않습니다. 내 목소리를 다시 들으려면 별도의 ‘녹음·다시 듣기’ 버튼을 눌러 한 번 더 말하세요. 녹음 파일은 이 브라우저의 메모리에서 재생합니다. 녹음 연습 중에는 마이크 연결을 재사용하고, 녹음 사이에는 오디오 트랙을 음소거합니다. 문장 인식 시작·홈·연습 완료·연결 끊기 때는 녹음 연결을 해제합니다. 짧은 화면 전환은 잠시 기다리고, 화면 이탈이 이어지면 연습을 중단합니다. 돌아온 뒤 버튼을 눌러 같은 문장에서 다시 시작할 수 있습니다. 브라우저의 마이크 표시가 연결 유지 중에도 보일 수 있어요. 권한을 다시 묻는지는 브라우저와 사이트 설정에 따라 달라요. 앱은 녹음을 서버에 저장하지 않습니다. 저장 버튼을 누르면 기기에 파일이 내려받아집니다.
  • Chrome·Edge 최신 버전에서 먼저 시도해 보세요. 지원 여부와 마이크 권한은 브라우저·기기마다 다릅니다. 음성인식이 지원되지 않아도 듣기와 가능한 경우 녹음 연습을 할 수 있습니다.
  • 학습 진도는 현재 브라우저에 저장합니다. 다른 기기와 자동으로 동기화되지 않으며, 브라우저 데이터를 지우면 사라집니다.
